# Envio manual do projeto ao GitHub

## 1. Criar o repositório

Acesse `https://github.com/new`, defina o nome **hileia-comercial-analytics** e escolha **Private**. Não marque as opções de README, `.gitignore` ou licença, pois o pacote já contém esses arquivos. Clique em **Create repository**.

## 2. Enviar os arquivos

Na página do repositório vazio, escolha **uploading an existing file**. Descompacte o arquivo `hileia-comercial-analytics-portable.zip` no computador, selecione todo o conteúdo da pasta extraída e arraste os arquivos e diretórios para a área de upload do GitHub.

No campo de mensagem, use `Versão portátil inicial` e clique em **Commit changes**. Nenhum segredo ou arquivo de ambiente está incluído no pacote.

## 3. Confirmar o endereço

Copie a URL do repositório, no formato `https://github.com/SEU-USUARIO/hileia-comercial-analytics`, e envie-a nesta conversa. Com essa URL confirmada, o próximo passo será criar o banco MySQL gratuito, o bucket de arquivos e o serviço web no Render.
